### Template Structure

#### Document Level (3 tabs)

- **Structure Tab**: Shows all blocks, add/remove/reorder blocks
- **Template Tab**: Name, language, country, subject, filename, digital signing options, header/footer text
- **Styles Tab**: Font, sizing, spacing, colors, margins, CSS editing

#### Module Level (3 tabs)

- **Settings Tab**: Display settings, margins, spacing specific to selected module
- **Columns Tab**: Add/delete/reorder/rename columns, set column width %
- **Styles Tab**: Font, size, color for specific module elements

### Variable Search Limitations

- ⚠️ Limited to 2 levels deep to avoid loops
- ⚠️ Minimum 3 characters in search
- ⚠️ Accent-sensitive search
- ✅ Example: `Invoice >> Project >> Number` (2 levels OK)
- ❌ Example: `Invoice >> Project >> Equipment >> Price` (3 levels NOT OK)

### Custom/Extra Input Field Variables

- Created in `Configuration > Extra Input Fields`
- Available as variables once added to a module
- Can be displayed on documents
- Can be added as columns in modules
- Searchable if enabled in field settings
- Format: `{$f.project.custom_1}` or named field

Validation (Webhook Security)

Copy
Incoming Request Headers:
├── Digest: sha512=<HMAC-SHA512 hash>
└── Date: <ISO timestamp>

Validation Process:
```javascript
// 1. Get raw request body
const rawBody = request.body;

// 2. Get Digest header
const digest = request.headers['digest'];
const [algo, hash] = digest.split('=');

// 3. Generate expected digest
const token = 'your_webhook_token';
const expectedHash = hmac(algo, rawBody, token);

// 4. Compare
if (hash === expectedHash) {
  // Webhook is authentic
  processWebhook(rawBody);
} else {
  // Reject webhook
  return 401;
}
